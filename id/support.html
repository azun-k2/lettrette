Pertanyaan umum

Mengapa Mac saya tidak bisa membuka winmail.dat?

Beberapa program email mengirim pesan dalam format mereka sendiri, TNEF, dan membungkus isi sebenarnya (teks berformat, gambar, dan lampiran) dalam file bernama winmail.dat. Mail di Mac dan iPhone tidak dapat membaca format itu, jadi Anda hanya melihat filenya. Buka dengan Lettrette untuk melihat pesan dan mengeluarkan lampirannya.

Bagaimana cara menyalakan pratinjau Lihat Cepat?

Di Mac, buka Pengaturan Sistem › Umum › Item Masuk & Ekstensi › Lihat Cepat, lalu nyalakan Lettrette. Kemudian pilih file winmail.dat atau .msg di Finder, atau lampiran di Mail, lalu tekan Spasi.

Bagaimana cara membuka lampiran dari Mail di iPhone atau iPad?

Sentuh dan tahan lampiran (atau ketuk), ketuk tombol Bagikan, lalu pilih Lettrette. Jika tidak ada di baris app, gulir ke ujung dan ketuk Lainnya untuk menemukannya.

Bisakah saya mengonversi banyak pesan sekaligus?

Ya. Gunakan ekspor massal untuk memilih beberapa pesan, atau seluruh folder, lalu ekspor semuanya sebagai EML, PDF, atau hanya lampirannya.

Sebuah pesan tampak salah. Apa yang bisa saya lakukan?

Beri tahu kami apa yang Anda lihat. Jika pesan tidak berisi hal pribadi, melampirkan file ke email Anda paling membantu; jika berisi, deskripsi atau tangkapan layar masalahnya sudah cukup. Jangan pernah mengirim file berisi konten pribadi.
